Mac 与 Windows 统一版本 v0.6.5。

- Windows 补齐 Mac 的白字/黑字快捷选择、使用示例和重置窗口。
- Windows 锁定后在文字框右上角保留独立“解锁 · 返回调整”，文字区域保持鼠标穿透；按钮随移动、缩放、隐藏同步。
- 字号、粗细、对齐、行距、内容透明度及背景底板集中展示，滑块显示当前值；按文档类型显示文字或 PDF 设置。
- 新增展示窗口位置、宽高的精确调整，并限制窗口留在可用屏幕内。
- 两端继续默认黑字、无描边；Windows 新用户默认中等字重、10 点额外行距，与 Mac 一致。已有偏好继续保留。
- 保留 v0.6.4 的 PDF 导入修复与 Windows 安装包精简。

Windows 请完整解压 ZIP 后运行 GlassText.exe；Mac 解压后将 GlassText.app 拖入“应用程序”。两端仍未取得平台代码签名或 Apple 公证。
