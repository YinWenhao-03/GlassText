# 使用指南

## 先完成一次最短流程

打开应用 → 输入文字或打开文件 → 调整位置 → 点击“锁定展示”。无需先改所有设置。

Mac 首次启动会展示四步截图引导，以后点击底部“新手引导”即可重看。Windows 在面板点击“新手引导”查看。

## 文字、PDF、Word 怎么选

纯文字可以自由改变字号和颜色。PDF 保留页面原有布局，使用页面缩放，不使用文字字号。Word 默认提取文字：图片、表格布局不保留。Mac 可在设置中选择使用 LibreOffice 保留版式；Windows 请先从 Word 导出 PDF。

编辑框内的草稿只有点击“显示这段文字”才会替换展示内容。导入失败时原内容会保留。

## 放大、缩小与平移

底部 `− / ＋` 的范围为 50%–300%；“重置”恢复 100%，PDF 对应适合当前窗口。纯文字缩放后会重新分页。

PDF 大于窗口时，在“外观”页使用平移方向按钮查看边缘。Mac 未锁定时也可在展示窗口用触控板滚动。锁定时请从控制面板操作。

## 锁定展示不等于锁定全部操作

Mac 在“设置…”中，Windows 在“设置”页中，分别勾选：

- **锁定时禁止翻页**：关闭手动翻页/跳页；Mac 同时暂停并禁止提词。
- **锁定时禁止缩放**：关闭放大、缩小、重置、字号调整及 PDF 平移。

未勾选时相应操作仍可在面板执行。窗口自身一直保持鼠标穿透，避免挡住下层应用。选择“返回调整”不会受上述限制。

## 找不到窗口怎么办

Mac 从菜单栏“透 → 恢复操作”找回；默认全局恢复键为 Control + Option + Command + G。Windows 从系统托盘图标选择“恢复操作”，或按 Ctrl + Alt + G。快捷键冲突时使用菜单入口。

Mac 设置里的“重置窗口”可重置位置。关闭控制面板不会结束应用，请从菜单栏或 Windows 面板“退出”结束。

## Mac 提词

在“提词”页开始，三秒倒计时后自动滚动；点击暂停会保留位置。PDF 不支持提词；Word 要以纯文字导入。可调速度或从头开始。

## 更新

退出正在运行的旧版本，再替换应用。Windows 必须完整解压新版文件夹，不要混用两个版本的文件。“查看更新”只打开发布页，不自动下载安装。
