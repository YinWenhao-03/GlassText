Mac 和 Windows 的透明文本框工具栏新增「开始提词／暂停提词」按钮。暂停后会保留位置，点击「继续提词」立即滚动；首次开始或从头播放时仍倒计时 3 秒。

- **Mac**：锁定后，解锁按钮旁仍可控制提词。在应用内也可按 `Shift + Command + P`。
- **Windows**：点击工具栏按钮即可进入连续提词模式。工具栏或控制面板有焦点时也可按 `Ctrl + Shift + P`。
- 提词适用于纯文字。启用「锁定时禁止翻页与提词」后，锁定时会暂停滚动并禁用提词按钮。

更新前请退出旧版。Mac 下载 `GlassText-macOS.zip`，解压后将 `GlassText.app` 拖入「应用程序」；Windows 下载 `GlassText-Windows-0.6.9-x64.zip`，完整解压后运行 `GlassText.exe`。两个压缩包的校验值见 `SHA256SUMS.txt`。
