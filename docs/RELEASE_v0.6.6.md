Mac 与 Windows 统一版本 v0.6.6。

- 操作按钮直接放在透明文本框上：锁定/解锁、翻页、缩放、重置缩放、置顶开关、内容、外观、设置与隐藏。
- Windows 工具栏随文本框移动和缩放；锁定后工具栏仍可操作，正文区域保持鼠标穿透。禁止翻页/缩放时，相应按钮禁用。
- Windows 窄窗口工具栏自动换行，并为正文保留工具栏下方的阅读区域。
- Mac 透明文本框补齐缩放、置顶开关、内容与设置快捷入口；锁定后继续提供独立解锁按钮。
- 保留 v0.6.5 的外观分组、滑块读数、黑白字快捷选择、精确窗口尺寸、示例和重置窗口。
- 默认黑字、无描边；已有外观和阅读记录继续保留。

Windows 请完整解压 ZIP 后运行 GlassText.exe；Mac 解压后将 GlassText.app 拖入“应用程序”。两端构建及自动检查均通过后才发布附件。应用仍未取得平台代码签名或 Apple 公证。
