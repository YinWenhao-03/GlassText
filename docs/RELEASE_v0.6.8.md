Windows 版修复了 PowerPoint 全屏放映盖住悬浮正文和工具栏的问题。勾选“置顶”后，GlassText 会自动恢复被放映窗口遮住的阅读窗口，恢复时键盘焦点留在 PPT。已用真实 PowerPoint 验证开始放映及换页后的窗口顺序。WPS 和双屏演讲者视图仍待实机验证。

本版也包含 v0.6.6 以来的 Windows 更新：

- 锁定正文后，悬浮工具栏仍可点击翻页和缩放。工具栏获得焦点时支持方向键及 Page Up / Page Down。
- 重复启动会唤回已有窗口，避免多组悬浮窗重叠。
- 文字阅读时按需加载 PDF 引擎，隐藏 PDF 时释放画布，暂停提词后停止动画循环。

**Windows 更新**：先在旧版控制面板点“退出”。关闭面板只会隐藏到托盘。完整解压 `GlassText-Windows-0.6.8-x64.zip` 后，从新文件夹启动 `GlassText.exe`。

macOS 构建同步版本号，本次功能修复针对 Windows。两个平台的 ZIP 均附 SHA-256 校验值。
