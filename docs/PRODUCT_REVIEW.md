# 交互设计

GlassText 的主要使用流程是：放入资料、调整阅读、锁定展示、恢复操作。

| 使用场景 | 设计 |
|---|---|
| 初次打开 | 内容、外观、提词分开；高级外观设置默认折叠 |
| 学习操作 | 四步截图引导，配合编号红框和操作说明 |
| 锁定展示 | 翻页和缩放分别设置锁定范围，控制面板保留恢复入口 |
| 阅读放大的 PDF | 方向按钮平移，重置按钮恢复适合窗口 |
| 鼠标穿透后调整内容 | 菜单栏/托盘、全局快捷键和控制面板均可恢复 |
| 关闭控制面板 | 应用继续运行，通过菜单栏或托盘找回；“退出”结束应用 |
| 打开 Word | 可选择提取文字或使用 LibreOffice 保留版式 |
| 导入失败或取消 | 保留当前资料 |
| 保存静态参考内容 | 固定当前画面，最多保留八个副本 |

## v0.6 调整

Windows 增加提词、阅读位置保存、显示器选择和恢复快捷键录入。高级外观选项放入折叠区域，设置页独立滚动，底部保留翻页与锁定按钮。

提词窗口关闭后台节流。PDF 重绘先取消上一任务，文档切换时丢弃过期结果。

测试结果见 [TESTING.md](../TESTING.md)，后续计划见 [ROADMAP.md](../ROADMAP.md)。
