# 透明文字 · GlassText

原生 macOS 透明内容展示工具，用于边操作边看资料。macOS 13+，文件仅在本机处理，无第三方运行依赖。

## 安装

从 Releases 下载 `GlassText-macOS.zip`，解压后将 GlassText.app 拖入“应用程序”。更新前请退出旧版本。

当前应用包面向 Apple Silicon；Intel Mac 可从源码构建。应用使用临时签名，尚未经 Apple 公证，首次启动可能需要在系统“隐私与安全性”中允许打开。

## v0.2：调整 → 锁定 → 恢复

1. 输入文字并点击“放映输入的文字”，或打开 PDF / Word / RTF / TXT / Markdown。
2. 调整模式显示边框和工具条。拖动内容移动窗口，拖动右下角缩放；文字随尺寸重新分页。
3. 点击“锁定展示”。边框和工具条消失，鼠标穿透，内容背景透明。
4. 按 **Control + Option + Command + G** 全局解锁并显示控制面板，或使用菜单栏“透 Aa → 恢复操作”。快捷键注册失败时，面板会提示使用菜单栏。

置顶与锁定互相独立。控制面板可关闭，菜单栏可重新打开。⌘O 打开文件、⌘0 显示控制面板、⌘I 切换锁定、⌘[ / ⌘] 翻页；这些快捷键仅在应用激活时生效。

## 内容与外观

- **文字**：中文自动分页，字号、颜色、自动黑白描边。调整字号或窗口时，保留原页首文字所在位置。编辑区草稿只有点击放映才替换当前内容。
- **Word**：提取纯文字，不保留图片、表格布局和原排版。需要版式时，请从 Word 导出 PDF。
- **PDF**：保留版式并适应窗口；默认去白底，可关闭去白底查看原页。PDF 模式隐藏文字字号/颜色控件。图片中的白色也会受影响；扫描阴影和彩色背景不保证去除。
- 文件读取/Word 转换在后台执行，显示正在读取的文件名；失败会提示原因并保留原有内容。
- 全局快捷键目前固定，不要求辅助功能权限；系统保留界面、系统快捷键冲突等情况仍可能影响它。

## 构建和验证

安装 Apple Command Line Tools 后：

```sh
bash scripts/build-app.sh
dist/GlassText.app/Contents/MacOS/GlassText --self-test
open dist/GlassText.app
```

构建产物为 `dist/GlassText.app` 与 `dist/GlassText-macOS.zip`。验证需在 macOS 图形登录会话内运行，会短暂打开测试窗口。

测试覆盖中文分页完整性、阅读位置保持、草稿隔离、锁定恢复状态、Word 转换、损坏/空文件、PDF 透明像素及原页切换。它们不替代跨应用全局快捷键、多显示器、复杂真实文档和长时间运行的人工验收。详见 `TESTING.md`。
